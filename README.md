# CourseC
Pequeño repositorio de C puro para aprendizaje basico

Pequeño curso propio de aprendizaje en lenguaje c en el que podre aprender de manera autodidacta el lenguaje de manera que pueda avanzar de poco en poco en el lenguaje.
El objetivo es entender las propiedas del lenguaje, algoritmos, funcionamiento, usos, etcterea y crear a futuro programas en el mismo
de manera basica se llevara a cabo mientras aprendo de manera paralela otros aprendizajes y lenguajes
